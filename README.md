# Portfolio Website - Vyankatesh Kalantri

A modern, interactive 3D portfolio website showcasing my professional journey and technical expertise. Built with React, Three.js, and TailwindCSS, featuring stunning 3D animations and responsive design.

## Key Features:
- Interactive 3D elements and animations using Three.js
- Responsive design that works on all devices
- Smooth scrolling and navigation
- Professional sections for About, Experience, Projects, and Contact
- 3D model integration with custom animations
- Contact form with EmailJS integration
- Dynamic star field background
- Project showcases with links to GitHub and research papers

## Technical Stack:
- React.js for frontend development
- Three.js for 3D graphics and animations
- TailwindCSS for styling
- Framer Motion for smooth animations
- EmailJS for contact form functionality
- Vite as the build tool
- GitHub Pages for deployment

## Sections:
1. Hero Section - Featuring an animated 3D robot model
2. About - Personal introduction and key skills
3. Experience - Professional timeline using vertical timeline component
4. Technology Stack - Interactive 3D spheres showing tech expertise
5. Projects - Showcasing key projects with descriptions and links
6. Testimonials - Feedback from colleagues and supervisors
7. Contact - Email form and social media links with 3D earth animation

The website demonstrates modern web development practices and creative design implementation, serving as both a portfolio piece and a testament to technical abilities.

## Setup Instructions:
1. Clone repository
2. Install dependencies with `npm install`
3. Configure environment variables for EmailJS
4. Run development server with `npm run dev`
5. Build for production with `npm run build`
